🔑 Secrets RDP — isi langsung dari dashboard fleksibel per akun

Setiap user isi secret-nya sendiri di repo hasil fork-nya. Kita cuma nyiapin template script — akun & password punya mereka. Dashboard akan enkripsi otomatis via GitHub API (libsodium).
Secret disimpan terenkripsi di GitHub (nama saja yang terbaca). Dashboard tidak pernah simpan password di server.
Setelah simpan, cek di Settings → Secrets and variables → Actions di repo fork kamu — nama secret akan muncul.
Jangan buat repo atau tambahkan secret baru untuk memulai RDP selama jeda. Bila repo lama tidak akan dipakai, buka pengaturan secret untuk menghapus/revoke yang sudah tidak dibutuhkan. Untuk repo template lama, nonaktifkan workflow dari tab Actions; perubahan template tidak otomatis masuk ke salinan lama.

Kontrol sesi

RDP BARU DINONAKTIFKAN Tidak ada durasi atau jalur akses yang dapat menyalakan sesi baru saat ini. Jangan membuat salinan repo tambahan atau mencoba dispatch manual untuk melewati jeda.
Langkah aman & bantuan akun
MATIKAN hanya mengirim stop ke run di repo yang sedang login; tidak dijalankan otomatis.
Run yang sudah berjalan tidak diubah oleh jeda ini. Periksa statusnya di panel Sesi. Jangan menekan MATIKAN jika kamu tidak ingin menghentikan run milik repo tersebut.
